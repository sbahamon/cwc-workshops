## Workshops

- [`ship-your-first-managed-agent/`](./ship-your-first-managed-agent) — *Ship Your First Managed Agent*: a Streamlit incident dashboard with an offline SRE Agent chat panel. You bring it online by implementing seven small functions in `agent.py`, each a single Claude Managed Agents API call. Its follow-on eval lab is in [`evals/`](./ship-your-first-managed-agent/evals/README.md).

Also in this repo, unchanged here from the upstream workshop collection: [`rightmodel/`](./rightmodel), [`agent-decomposition/`](./agent-decomposition), [`how-we-claude-code/`](./how-we-claude-code), [`agent-battle/`](./agent-battle), [`agents-that-remember/`](./agents-that-remember), [`eval-driven-agent-development/`](./eval-driven-agent-development), [`production-ready-agent/`](./production-ready-agent), [`research-desk/`](./research-desk). Each folder's README describes its workshop.
